# Mot : téléchargement

**Mot** est un traitement de texte pour Windows qui ouvre, affiche et enregistre les documents Word (.docx) avec la même mise en page que Word. Il lit aussi les fichiers .doc, .rtf, .odt et .txt.

## ⬇️ [Télécharger Mot pour Windows](https://github.com/Lholleville/mot-telechargement/releases/latest/download/Mot-Installation.exe)

Environ 45 Mo. Windows 10 (version 1809 ou plus récente) ou Windows 11, 64 bits. Rien d'autre à installer.

## Installer

1. Lancer `Mot-Installation.exe`.
2. Si Windows affiche « Windows a protégé votre ordinateur » (l'installateur n'est pas signé) : cliquer sur **Informations complémentaires**, puis **Exécuter quand même**. Le navigateur peut aussi demander de confirmer le téléchargement (« Conserver »).
3. Suivre l'assistant : pas besoin de droits d'administrateur. Mot apparaît ensuite dans le menu Démarrer.

Pour ouvrir les documents Word avec Mot d'un double clic : clic droit sur un fichier .docx › **Ouvrir avec** › **Choisir une autre application** › **Mot** › **Toujours**.

## Mettre à jour

Télécharger de nouveau avec le lien ci-dessus et lancer l'installateur : il remplace l'ancienne version. Réglages et documents sont gardés. Les versions précédentes sont dans les [releases](https://github.com/Lholleville/mot-telechargement/releases).

## Désinstaller

Paramètres › Applications › Mot › Désinstaller.

## Polices

Les documents récents de Word utilisent la police Aptos, fournie avec Microsoft 365. Sans elle, Mot la remplace par une police proche : le texte reste lisible, mais les coupures de lignes peuvent différer de celles de Word.
